# 极米投影仪 × 米家 / 小爱同学 语音控制桥

一块 ESP32 开发板，把极米投影仪接入米家——

> **「小爱同学，打开投影」** → 投影仪开机
> **「小爱同学，关闭投影」** → 投影仪关机

不需要拆机、不需要公网 IP、不需要 Home Assistant，一块十几块钱的 ESP32 插上 USB 就能用。
已实测可用机型：**极米 Play5**（同协议的极米型号大概率通用，欢迎反馈）。

---

## 工作原理

```
 小爱音箱 / 米家 App
        │  语音指令
        ▼
   巴法云 MQTT（免费物联网云平台）
        │  下发 on / off
        ▼
     ESP32 ──┬── 开机：BLE 广播重放（伪装成遥控器按电源键）
             └── 关机：WiFi UDP → 投影仪 16735 / 16750 端口
                      │
                      ▼
                  极米投影仪
```

**为什么开机必须走蓝牙？**
极米投影仪关机后 Wi-Fi 模块整体断电，任何网络指令都叫不醒它。遥控器的电源键本质上是一包
BLE 广播报文（内含这台遥控器专属的 token），投影仪待机时只认这个。所以固件做了"学习模式"：
把遥控器按一次电源键的广播**学一遍存进 Flash**，之后原样重放即可——每台遥控器的报文不同，
必须现抓，好在只需要学一次。

## 准备工作（10 分钟）

### 1. 注册巴法云，拿到私钥

1. 打开 [cloud.bemfa.com](https://cloud.bemfa.com/) 注册账号（**记住登录方式**，之后米家绑定要用同一个账号）
2. 登录后进控制台，右上角能看到一串 32 位的 **私钥（uid）**，复制保存

### 2. 创建一个主题

1. 控制台左侧 →「MQTT 设备云」→ 新建主题
2. 主题名随意，但**结尾必须是 `006`**，例如 `myproj006`
   （巴法云规则：主题名后三位决定设备类型，`006` = 开关，才会同步到米家）
3. 点主题的「更多 / 编辑」，把**昵称**改成你想对小爱喊的名字，例如「投影」
   > 💡 这个昵称就是米家/小爱里的设备名。建议避开"投影仪"三个字以外的歧义词，
   > 也不要和家里已有的米家设备重名。

## 快速开始

### ① 安装 PlatformIO 并烧录

电脑装好 [VS Code](https://code.visualstudio.com/) 和 [PlatformIO 插件](https://platformio.org/install/ide)，
克隆本项目并用 VS Code 打开文件夹，PlatformIO 会自动装好依赖，然后：

- 底部状态栏点 **→（Upload）** 烧录；或命令行：

```bash
pio run -t upload          # 烧录（macOS 端口一般是 /dev/cu.usbserial-xxxx）
pio device monitor         # 查看运行日志
```

> 固件里**没有写死任何账号信息**，全部通过下一步的配网页面填写。

### ② 配网（首次必做）

烧录后 ESP32 会自动打开配网热点：

1. 手机 Wi-Fi 列表连接 **`JimiPlay5-Setup`**，密码 **`12345678`**
2. 会自动弹出配网页（没弹就浏览器访问 `192.168.4.1`），页面是中文的，填四项：
   - 家里 Wi-Fi 名称（**必须 2.4GHz**，ESP32 不支持 5GHz）
   - Wi-Fi 密码
   - 巴法云**私钥**（准备工作第 1 步拿到的）
   - 巴法云**主题名**（准备工作第 2 步创建的，如 `myproj006`）
3. 点保存，设备自动连接路由器

> 以后换了路由器连不上时：**按住板上 BOOT 键再上电**，会强制重新进入配网模式。

### ③ 打开网页控制台

设备联网后，浏览器访问：

- `http://jimiplay5.local`，或
- 设备 IP（在路由器后台 / 巴法云控制台看，也可以串口命令 `info` 查看）

控制台里可以：查看在线状态、学习遥控器、测试开关机、补改参数（投影仪 IP、私钥、主题）。

### ④ 学习遥控器开机广播 ★唯一必须动手的一步

1. 控制台点「**开始学习（按一下遥控器电源键）**」
2. 把极米遥控器**贴近 ESP32（10cm 内）**，按一下**电源键**
   （投影仪关机状态也可以，按的是遥控器不是投影仪）
3. 抓到广播后 2.5 秒自动停止并保存，最多等 90 秒
4. 点「测试开机」验证——投影仪应当亮起

串口会打印类似：

```
[BLE] 捕获极米广播 #1  MAC=xx:xx:xx:xx:xx:xx  RSSI=-45  0201050303121813ff4600...
[BLE] 已保存广播报文：0201050303121813ff4600...
```

> 抓不到：多按两下、离近一点、确认按的是**电源键**。

### ⑤ 填投影仪 IP（关机功能需要）

投影仪开机 → 设置 → 网络信息 → 看 IP；或在路由器后台找名字含 `XGIMI` 的设备。
填到控制台「③ 参数设置」→「投影仪局域网 IP」→ 保存。

> ⚠️ **强烈建议在路由器里给投影仪做 DHCP 静态绑定（IP-MAC 绑定）。**
> 投影仪每次开机可能被分到不同 IP，IP 一变关机指令就发不出去了（开机不受影响）。

### ⑥ 绑定米家，开始喊话

1. 米家 App → **我的** → **其他平台设备**（部分版本叫"连接其他平台"）→ 右上角**添加**
2. 找到 **巴法**，登录巴法云账号 —— ⚠️ **必须和拿私钥的是同一个账号**（本项目踩过的坑，见 FAQ）
3. 登录后点「**同步设备**」
4. 对小爱说：**「打开投影」「关闭投影」**

想用更自然的指令（比如"小爱同学，看电影"）：米家 → 智能/场景 → 手动执行 → 动作选这台设备 → 开。

## 排错指南（FAQ）

先看串口日志（`pio device monitor` 或 `python tools/serial_log.py`），大部分问题一眼可见。

| 现象 | 原因与解决 |
|---|---|
| 小爱说"没有找到设备" | ① 米家绑定的巴法账号**不是**创建主题的那个账号（最常见！网页控制台和米家里务必用同一种登录方式）；② 改完昵称后没回米家点「同步设备」；③ 主题名结尾不是 `006` |
| 点"开始学习"页面就断 / 设备重启 | 老版本固件的 Wi-Fi/BLE 共存冲突（`WiFi.setSleep(false)` 时启蓝牙会 abort）。本项目固件已修复，确认你用的是仓库最新代码 |
| 抓不到遥控器广播 | 遥控器离 ESP32 太远（贴近 10cm）、按错键（要**电源键**）、或者型号广播格式不同 |
| 开机没反应但日志显示已广播 38 字节 | 老版本 bug（报文被错误补前缀超过 BLE 31 字节上限被截断）。最新固件已修复并会告警 |
| Wi-Fi 显示"找不到 AP"（reason 201），但扫描看得到 | 路由器用了老式 **WPA/TKIP** 加密，被 ESP32 默认的 WPA2 门槛过滤。固件已放宽到 WPA；也建议路由器改回 WPA2/WPA3（更安全） |
| 开机正常，过几天关机失效 | 投影仪 IP 变了。去路由器做 DHCP 静态绑定 |
| 重启后自己开机 | 已修复：巴法云会把主题上最后一条消息回放给新订阅者，固件在订阅后 4 秒内忽略 |
| 电脑 MQTT 客户端一连，设备就掉线 | 正常：巴法云 clientID 必须等于私钥，同私钥只能一个连接。调试用 `tools/bemfa_test.py on`（走 HTTP，不占 MQTT 连接） |
| 米家里列表是空的 | 这类第三方平台设备**不出现在米家首页**，只在「我的 → 其他平台设备 → 巴法」里；能不能用只看小爱喊得动不动。列表空 + 小爱喊不动 → 99% 是账号不对 |
| 米家状态显示和投影仪实际状态不符 | 固件只记录"最后一条指令"，不知道投影仪真实状态。不影响语音控制 |
| 921600 烧录失败 | 部分板子/线材不支持，`platformio.ini` 里已用 460800 |

## 电脑端调试工具

```bash
export BEMFA_UID=你的私钥
export BEMFA_TOPIC=你的主题

python tools/bemfa_test.py on          # 云端发"开"（等效小爱喊话）
python tools/bemfa_test.py off         # 云端发"关"
python tools/bemfa_test.py status      # 看主题最新一条消息
python tools/bemfa_test.py udp 192.168.1.50   # 电脑直接发 UDP 关机（验证关机通道）
python tools/serial_log.py 600         # 把 ESP32 串口日志记录到文件 10 分钟
```

## 串口命令

| 命令 | 作用 |
|---|---|
| `on` / `off` | 直接开关（不经过云端） |
| `learn` / `save` | 开始学习 / 结束并保存 |
| `scan` | 扫描周边 Wi-Fi（信道、加密方式，排查连不上） |
| `setip 192.168.1.50` | 写投影仪 IP |
| `settopic myproj006` | 改巴法云主题 |
| `clear` | 清除已学的开机广播 |
| `ip` / `adv` / `info` | 查看当前配置 |

## 协议备忘（写给想扩展的人）

| 动作 | 通道 | 报文 |
|---|---|---|
| 开机 | BLE 广播 | 完整 AD 结构，如 `02 01 05` + `03 03 12 18` + `13 FF 46 00 <token>`（`46 00` = 极米厂商 ID 0x0046）；BLE 传统广播 payload 上限 31 字节 |
| 关机 | UDP → 投影仪:16735 | `KEYPRESSES:30` |
| 快速关机 | UDP → 投影仪:16750 | `{"action":20000,"controlCmd":{"delayTime":0,"mode":6,"time":0,"type":0},"msgid":"2"}` |
| 其他按键 | UDP → 投影仪:16735 | `116` 电源、`35` 主页、`48` 返回、`49` 确定、`114/115` 音量、`36/37/38/50` 方向 |
| 云端 | MQTT | `mqtt.bemfa.com:9501`，**clientID = 私钥**，消息 `on` / `off`；主题名后三位决定设备类型（001 插座 / 006 开关…） |

固件里几个关键的坑，改代码前建议先看 `src/main.cpp` 里的注释：

- **Wi-Fi/BLE 共存**：`WiFi.setSleep(false)`（WIFI_PS_NONE）状态下启用蓝牙控制器，
  ESP-IDF 会在 `coex_core_enable()` 里直接 abort 重启（官方 issue #9595）。
  固件在 `bleInit()` 里先 `esp_wifi_set_ps(WIFI_PS_MIN_MODEM)` 再开蓝牙。
- **扫描占空比**：BLE 扫描 interval/window 不能拉满，否则把 Wi-Fi 饿死（MQTT 断线、网页打不开）。
- **广播报文原样重放**：学到的完整 AD 结构不要再拼前缀，否则超 31 字节被截断。

## 隐私与安全说明

- 本仓库代码**不含任何个人密钥、Wi-Fi 信息**；你自己的私钥只保存在 ESP32 的 Flash 里
- ⚠️ 如果你修改代码把自己的 Wi-Fi/私钥写死进去，**不要把改好的代码上传到公开仓库**
- 巴法云私钥泄露 = 别人能控制你绑定在它上面的所有设备，注意保管
- BLE 报文重放只应作用于**自己的**投影仪
